Practical Tasks (PDF Section 38 Audit)

1 HelloServlet (doGet)

Maps to /hello. Handles HTTP GET requests and responds with formatted HTML. Also accepts optional GET query parameter ?name=....

Raw GET /hello

2 Student Form (POST)

Submits student form with POST to /student. Server extracts name, email, and course using request.getParameter() and stores the student into session.

Open Student Form (POST)

3 HttpSession & Login Flow

PDF Section 33: Login form submitting credentials (admin / 1234) to LoginServlet (/login) which creates an HttpSession and stores username.

Open Student Login Form Access /home directly

4 Logout (session.invalidate)

Calls LogoutServlet at /logout. Destroys the active session using session.invalidate() so subsequent attempts to access /home are blocked.

Execute Logout (/logout)

5 Filters & Request Interception

• MyFilter (/*): Intercepts all requests, logs request URIs to server logs, and delegates via chain.doFilter().
• AuthFilter (/home): Guards protected HomeServlet. Redirects unauthenticated requests to login.

Test Protected Resource (/home)

6 Event Listeners

• AppListener: Implements ServletContextListener (logs "Application Started" and "Application Stopped").
• SessionListener: Implements HttpSessionListener (logs "Session Created" and "Session Destroyed").

Trigger Session Event
